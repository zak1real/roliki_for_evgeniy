# Секция роллерспорта — сайт

Сайт секции роллерспорта Федерации роллер спорта Нижегородской области. Чистые HTML и CSS, немного JavaScript, без сборки.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Структура

```
.
├── index.html       # Главная: первый экран с видео, ленты, о секции, место, тренеры, цены, фото
├── contact.html     # Запись: форма, телефоны тренеров, адрес, карта
├── css/style.css    # Стили обеих страниц (цвета — переменные в :root)
├── js/main.js       # Общий скрипт обеих страниц
└── assets/
    ├── images/      # Фото и логотипы
    └── video/       # Видео (MOV с кодеком H.264 — играет во всех браузерах)
```

Шапка и подвал продублированы в обоих HTML-файлах: при изменении меню правьте обе страницы.

## Оформление

- Тёмная тема, акценты — красный и синий из логотипа федерации (`--red`, `--blue` в [css/style.css](css/style.css)).
- Шрифты Unbounded (заголовки) и Manrope (текст) подключаются с Google Fonts в `<head>` каждой страницы.
- Логотипы:
  - `logo-light.png` — версия для тёмного фона (белый текст, прозрачный фон). Стоит в шапке, подвале и блоке «Приходите на тренировку».
  - `logo1.png` — оригинал с чёрным текстом на прозрачном фоне, используется как иконка вкладки.
  - `logo.jpg` — оригинал на белом фоне, на сайте не используется.
  Если федерация пришлёт новый логотип, светлую версию нужно сделать заново: чёрный текст → белый, цветные части без изменений.

## Что делает main.js

- Шапка получает фон при прокрутке; на экранах уже 900px меню открывается кнопкой-бургером.
- Блоки с атрибутом `data-reveal` плавно появляются при прокрутке (задержка — переменная `--i` в `style`). Цифры с `data-count` отсчитываются от нуля.
- Видео на первом экране играет без звука по кругу; кнопки в углу ставят на паузу и включают звук.
- Фото в разделе «Фото» (`data-gallery-item`) открываются на весь экран, листаются стрелками и клавишами ← →.
- Форма записи (только на contact.html) — см. ниже.

Если у посетителя в системе включено «уменьшение движения», анимации, бегущие ленты и автозапуск видео отключаются.

### Как добавить фото в галерею

Скопируйте в `index.html` блок `<button class="bento-item" ...>` внутри `.bento`, поменяйте `src`, `alt` и подпись `bento-caption`. Класс `bento-wide` растягивает фото на две колонки, `bento-tall` — на две строки. Подпись при просмотре берётся из `alt`.

## Форма записи

Сервера нет: по кнопке «Отправить заявку» [js/main.js](js/main.js) проверяет имя, телефон и группу и открывает почтовый клиент посетителя с готовым письмом. Адрес получателя — атрибут `data-email` у формы в [contact.html](contact.html). Группа выбирается кнопками (radio `name="group"`).

## Карта

На странице контактов — виджет Яндекс Карт (`<iframe>` с адресом в параметре `text`). Кнопка «Построить маршрут» на главной ведёт на Яндекс Карты с тем же адресом. Чтобы сменить адрес, замените текст в обоих местах.

## Что нужно заполнить

- Второй тренер: имя «Дмитрий Какойто» и телефон `+7 (000) 000-00-00` — заглушки (в `index.html` и `contact.html`). Фото у его карточки сейчас не портрет тренера, а снимок учениц.
- Цены в разделе «Сколько стоит» сейчас «по запросу».
